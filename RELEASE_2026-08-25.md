# Smart Learning Lab Backend Release — 2026-08-25

This release is based on the supplied `smartlearninglab (2)` source.

### Fixed
- MongoDB parallel multikey index regression for `category_ids` + `subcategory_ids`.
- Admin course creation HTTP 500 caused by that index.
- Bulk PDF → Course HTTP 500 caused by that index.
- Admin Learning Library web upload HTTP 422 caused by incorrect multipart file construction.
- Course/Lesson resource web uploads use the same cross-platform multipart path.
- Startup automatically repairs the unsafe production indexes.

### Deployment
Use `uvicorn app.main:app --host 0.0.0.0 --port $PORT` (Render config already points to `app.main:app`).
The backend must be deployed before the frontend so the MongoDB index repair runs once.
