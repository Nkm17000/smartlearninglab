# AI / Search Fix

The AI Tutor now receives the exact user question plus recent conversation history and retrieves relevant published lessons/courses before answering. When `AI_API_KEY`/`OPENAI_API_KEY`/`GROQ_API_KEY` is configured, the answer is generated by an OpenAI-compatible model. Without a key, a deterministic course-grounded fallback is returned instead of an unrelated answer.

AI Studio endpoints now use learner statistics and weak topics consistently for Coach, Quiz, Study Plan and Career Roadmap. Global search now ranks title/exact matches, token matches and searches courses, lessons, questions and topics.

Set the AI provider variables in `.env`, then run `uvicorn main:app --reload`.
