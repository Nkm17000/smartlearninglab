# Smart Learning Lab - Content Portal Update

The backend now supports:
- Fixed course categories with validation.
- Course and lesson resource metadata.
- Multipart uploads for PDF/video/audio/document/image/other resources.
- MongoDB GridFS storage using the `sll_media` bucket.
- Admin Student Resource Library.
- Student Resource Library with category filtering.
- Streaming media endpoint for uploaded files.
- Course overview now includes course-level resources.
- Lesson endpoint now includes lesson resources.

Install dependencies with `pip install -r requirements.txt`.
